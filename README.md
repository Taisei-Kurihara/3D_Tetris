# 3D Tetris

3D空間でテトリスをプレイするゲームです。

## 操作方法

### キーボード操作

| 操作 | キー |
|------|------|
| **移動** | |
| 前後移動 (X軸) | W / S または 上矢印 / 下矢印 |
| 左右移動 (Z軸) | A / D または 左矢印 / 右矢印 |
| **回転** | |
| X軸回転 | I (負方向) / K (正方向) |
| Y軸回転 | U (負方向) / O (正方向) |
| Z軸回転 | J (負方向) / L (正方向) |
| **その他** | |
| 落下開始 | Space |
| 即時落下 (ハードドロップ) | B |
| ポーズ | P |
| X-ray視点調整 | Q (下層表示) / E (上層表示) |

### ゲームパッド操作

| 操作 | ボタン |
|------|--------|
| 移動 | 左スティック |
| 回転 | 右スティック |
| 視点操作 | 右スティック |

## ゲームルール

- ミノ (ブロックの塊) が上から落下してきます
- ミノを移動・回転させて配置します
- X方向またはZ方向に一列揃えるとライン消去されます
- 斜め方向 (対角線) でもライン消去が可能です
- ブロックが上限を超えるとゲームオーバーです

## 機能

- **ゴースト表示**: ミノの落下予測位置が水色で表示されます
- **X-ray視点**: 上層のブロックを透明化して下層を確認できます
- **回転・移動矢印**: 操作可能な方向が矢印で表示されます
- **スコアシステム**: ライン消去でスコアを獲得できます

## スコア計算

```
スコア = ((削除ブロック数 × 10) + ((削除ライン数 × 2) × 100)) × 削除ライン数
```
